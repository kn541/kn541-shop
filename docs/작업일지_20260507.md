## 1. 작업 개요

쇼핑몰 메인(홈) 헤더의 레이아웃을 단순화하고, 페이지마다 흩어져 있던 3종 헤더를 하나로 통일했다.

### 창님 1차 요구사항
1. 로고를 신규 CI(scm.kn541.co.kr 동일 로고)로 교체
2. 메뉴 구성: 홈 → 카테고리 데이터 → 사전예약 → 벨류업 (베스트/신상품/추천상품 제거)
3. 검색폼을 헤더 가운데로 이동
4. 우측 장바구니/마이페이지를 아이콘 빼고 한글 텍스트로
5. 비로그인 시 로그인/회원가입 노출, 로그인 시 마이페이지 노출

## 2. 사전 분석 (MCP 활용)

### 2-1. 레포 구조 파악
- `Header/Header.tsx` — 카테고리 등 일반 페이지 헤더
- `Header/Header2.tsx` — `(home-2)` 변형 페이지 헤더
- `main-page/MainHeader.tsx` — 홈 페이지 전용 헤더 (categoryTabs prop 받음)
- → 페이지마다 다른 헤더를 사용하는 분산 구조

### 2-2. 카테고리 DB 실데이터 확인 (Supabase MCP)
```sql
SELECT category_code, category_name, depth, sort_order, is_active
FROM categories WHERE depth = 1 ORDER BY sort_order;
```
- depth=1 활성 카테고리 11개: 생활/홈데코, 가전/컴퓨터/디지털, 주방, 뷰티, 자동차/스포츠, 유아동/주니어, 여행, 패션/잡화, 건강/헬스, 캠핑/등산/낚시, 식품
- **베스트/신상품/추천상품/사전예약상품/벨류업상품은 DB에 없음** → 정적 하드코딩(`HOME_TABS`)

### 2-3. 로고 코드 상태
- `components/Logo.tsx`는 이미 SCM 동일 Supabase URL을 사용 중
  - `https://ghtkropmnrelkxivzpim.supabase.co/storage/v1/object/public/assets/kn541-logo.png`
- 단, `MainHeader`는 `MAIN_PAGE_ASSETS.logos.main`(별도 PNG) 사용 → 화면에 구 로고 표시 원인

## 4. 이슈 발견 — 홈은 변경 미적용

### 증상
1단계 배포 후 카테고리 페이지(`/products` 등)는 새 헤더로 정상 표시되었으나, **홈 페이지(`/ko`)는 기존 디자인 그대로**.

### 원인
- `(home)/layout.tsx`가 `header={<MainHeader categoryTabs={...} />}`로 별도 헤더 명시 주입
- `MainHeader`는 `HOME_TABS`(홈/베스트/신상품/추천상품/사전예약상품/벨류업상품 정적 6개) + `categoryTabs` 결합 표시
- `(home-2)/layout.tsx`도 `Header2` 별도 주입 (또 다른 변형)
- → 페이지별 헤더 3종 분산이 통일성 부재의 근본 원인

### 처리 방침
- 옵션 A(레이아웃에서 별도 헤더 주입 제거 → 기본 `Header` 사용)와 옵션 B(`MainHeader` 자체 재작성) 중 **A 선택** (창님 컨펌)
- 이유: 헤더 분리 유지 시 변경마다 다중 수정 부담 → 단일 헤더로 운영 단순화
